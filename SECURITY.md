# Security Policy

## Supported versions

Security fixes are currently provided for the latest published beta only.

## Reporting a vulnerability

Please do not publish exploitable details in a public issue. Use GitHub's
private vulnerability reporting feature when it is enabled for the repository.

Include:

- affected version;
- reproduction steps;
- expected and actual behavior;
- whether source games, saves, cache, or Vnite metadata may be affected.

Vnite Game Cache performs file copy and cleanup operations. Test reports should
use disposable data and must not include personal paths, save files, database
files, credentials, or NAS access information.
