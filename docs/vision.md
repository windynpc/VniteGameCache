# Vision

## 项目目标

让用户把大量本地单机游戏长期存放在 NAS，通过 Vnite 统一管理，并在需要游玩时自动使用本地 SSD 获得接近本地安装的体验。

用户正常流程应当只有：

1. 在 Vnite 点击游戏。
2. 首次等待索引和缓存。
3. 游戏从本地 SSD 启动。
4. 游戏退出后自动同步存档。
5. 第二次启动不再等待完整扫盘。

## 核心价值

项目主要解决四个问题：

1. NAS 上大量游戏反复扫盘耗时。
2. SMB 直接运行大量小文件游戏延迟高、兼容性差。
3. 手动复制游戏到 SSD 容易忘记同步存档。
4. 本地 SSD 空间有限，需要自动保留常玩游戏并清理冷缓存。

## 目标用户

主要面向：

- Galgame 玩家
- RPG Maker 游戏玩家
- 独立游戏玩家
- DRM-free 游戏玩家
- 使用 Windows + NAS 的个人用户
- 希望管理大量本地游戏元数据的 Vnite 用户

## 非目标

第一阶段不服务于：

- 强 DRM 游戏
- 依赖官方更新器和反作弊的在线游戏
- Steam 大型在线游戏的安装管理
- 块级透明缓存
- 多用户分布式游戏存储
- 游戏文件去重平台
