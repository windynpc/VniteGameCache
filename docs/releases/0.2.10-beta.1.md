# Vnite Game Cache 0.2.10-beta.1

本次版本同步了此前仅安装在本地的 VGC 功能和控制台改进。

## 更新内容

- 可选的 ZIP、7z、RAR 压缩包预览与导入；首次使用按需解压到指定 SSD 缓存，已就绪的缓存重复启动不再解压。自动发现仅检查配置根目录的第一层，候选不明确时仍需人工确认。
- 控制台显示压缩包来源、缓存准备状态、MTool 与翻译启动候选；增加单游戏的源包、缓存和隔离缓存空间明细，以及手动触发的实际占用核算。
- 单游戏清除缓存进入 Quarantine，增加恢复入口和更明确的删除范围提示；活动隔离缓存或存档索引会阻止可能丢失恢复信息的记录删除。
- 接管命令增加本次请求回执与重复提交保护；沿用现有 Wrapper、Agent 和 Schema 5 数据链路。
- 调整翻译 EXE、MTool 启动候选与进程跟踪规则。

## 已验证与限制

- 已在隔离环境验证 ZIP 导入、Wrapper 启动、缓存复用与存档保护；本地控制台构建和测试通过。
- 本轮没有对日常游戏执行清理或删除，也没有补做用户已暂停的真实界面验收。RAR 的真实游戏样本、NAS 到 E: 的大包传输耗时，以及“停止游戏”按钮对所有 MTool 派生进程的行为，仍需按具体游戏确认。
- 压缩包候选检测不保证自动识别正确主程序。导入前请确认游戏名与启动程序；已有非空缓存不会被新版源包静默覆盖。
